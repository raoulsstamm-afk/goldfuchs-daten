# Goldfuchs Daten

Öffentliche Meldungen aus SEC EDGAR (Formular 13F), automatisch zusammengefasst: welche Positionen neu, aufgestockt, reduziert oder verkauft wurden, mit Datum und Link zur Originalmeldung.
Nur Fakten aus öffentlichen Meldungen. Keine Anlageberatung, keine Empfehlung, keine Kurse, keine Renditen.
